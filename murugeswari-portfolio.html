Project Overview

During my time at Sofia Infology, I developed a complete Customer Information Management System tailored for their mobile service business. The system was built using HTML for the front-end interface and PHP for backend server-side logic, connected to a MySQL database for persistent data storage. The application enables staff to register new customers, update service records, and retrieve customer data quickly through a clean, easy-to-use web interface — significantly reducing the reliance on manual, paper-based processes. This project gave me hands-on experience with full-stack web development in a real production setting, including form handling, data validation, and database query optimisation.
